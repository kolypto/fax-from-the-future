# Факсы из будущего.

Короткая фантастическая история Марка Вартаняна: двенадцать факсов из будущего и комментарии автора.

[Читать книгу](https://kolypto.github.io/fax-from-the-future/)

Сайт собран на Hugo. Запуск через [mise](https://mise.jdx.dev/):

```sh
mise run serve  # http://localhost:1313/
mise run build # сборка в public/
```
